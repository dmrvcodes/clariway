# Progress: 21 November 2026

## Scope completed

- Local audit of the first 20 `<audio>` and `<video>` elements on the current
  page with no additional extension permissions.
- Three explicit media-accessibility states: caption track available,
  transcript available, or missing captions/transcript.
- Detection of author-provided `captions` and `subtitles` tracks, including
  language, label, mode, and loaded cue count.
- Detection of transcripts exposed through `aria-describedby`, inline
  transcript containers, or explicit transcript/caption links.
- Extraction and normalization of loaded text-track cues into a bounded local
  transcript preview.
- Side-panel media report with totals, per-element evidence, track languages,
  duration when available, and a missing-text-alternative count.
- English TTS for an available transcript, reusing the existing voice selector
  and stop behavior.
- Runtime schema validation for the complete media audit added to `PageContext`.

## State model

```text
audio/video
  ├─ captions/subtitles <track> exists → captioned
  ├─ inline/linked/ARIA transcript exists → transcript
  └─ neither exists → missing
```

Caption-track presence and transcript presence are kept separate from cue
availability. A cross-origin or not-yet-loaded track can be correctly reported
as captioned even when the browser does not expose its cue text to Clariway.

## Verification

Run:

```bash
npm run verify
```

The executable fixture covers:

- video with an English captions track and two loaded cues;
- track language, mode, cue count, and normalized transcript extraction;
- audio with an inline transcript referenced by `aria-describedby`;
- audio with a linked transcript whose contents are not fetched;
- video missing both captions and a transcript;
- aggregate media counts and all three audit states;
- all existing image-audit, hybrid prompt, crop, Apply, and Undo regressions.

## Deliberate limits

- This scope audits author-provided accessibility data; it does not record tab
  audio or perform speech-to-text.
- Cross-origin text-track metadata can be audited, but cue text may remain
  unavailable because of browser/CORS restrictions.
- Linked transcript pages are reported as evidence but are not fetched or sent
  to Firebase.
- Live caption generation and tab-audio capture are deferred to a separate
  privacy and permissions design.
