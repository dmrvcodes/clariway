# Progress: 20 November 2026

## Scope completed

- Firebase AI Logic hybrid image descriptions using `PREFER_ON_DEVICE` with
  automatic cloud fallback.
- Structured output validated as `{ altText, explanation }`; malformed,
  oversized, or empty responses fail closed.
- Actual Firebase `inferenceSource` is displayed for every generated result.
- Local visible-tab capture and per-image crop. Cross-origin image URLs are not
  fetched and no host permissions were added.
- Fresh image geometry is captured immediately before inference to reject stale
  page state.
- Bounded page title, description, and nearby text are marked as untrusted model
  context to reduce prompt-injection risk.
- Single-image generation and sequential batch generation for at most three
  visible missing images.
- Human review before mutation. A generated description can be applied only as
  a reversible preview in the current DOM; the original `alt` attribute is
  restored exactly by Undo.
- Content-script mutations verify both the stable audit ID and expected image
  source. A changed page fails closed and requires a new audit.

## Runtime flow

```text
user click
  ├─ initialize on-device model (user activation)
  ├─ refresh page audit + bounding rectangles
  ├─ capture visible viewport under activeTab
  ├─ crop selected image locally
  └─ Firebase PREFER_ON_DEVICE
       ├─ Chrome on-device multimodal model
       └─ Firebase cloud fallback
            ↓
       structured result + inferenceSource
            ↓
       review → apply preview → undo
```

## Manual acceptance checklist

1. Run `npm run build` and reload `dist` in `chrome://extensions`.
2. Open a regular HTTP/HTTPS page with at least one visible image missing `alt`.
3. Click the Clariway toolbar action and run **Audit current page**.
4. Click **Describe this image** or the max-three batch action.
5. Confirm the result includes a crop, concise English alt text, explanation,
   and an inference-source badge.
6. Click **Apply preview fix** and verify the missing count decreases.
7. Inspect the page image and verify the generated `alt` attribute.
8. Click **Undo preview fix** and verify the exact original attribute state and
   missing count are restored.
9. Scroll the target outside the viewport and confirm generation requests an
   in-view image instead of uploading an unrelated crop.

## Known limitations

- The MVP analyzes only the visible portion of an image. Full-page and lazy-load
  traversal are deliberately deferred.
- Batch inference is capped at three visible missing images to bound latency,
  quota, and accidental cloud cost.
- On-device multimodal inference depends on compatible Chrome hardware/model
  availability. Chrome may require the Prompt API multimodal flag; otherwise the
  configured Firebase cloud model handles the request.
- Generated alt text is a suggestion and requires human review. Clariway does
  not persist edits to the source website or CMS.
- Interactive images may need a control name rather than a visual description;
  the reviewer remains responsible for validating the generated function text.
