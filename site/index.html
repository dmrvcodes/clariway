Clariway

A privacy-first Chrome accessibility assistant for visual and spoken web content.

View source Install locally

Hybrid AI, with a visible privacy boundary

  1. Audit locally. Clariway finds missing image descriptions and media accessibility gaps in the active tab.
  2. Describe on device. Gemini Nano is used first when Chrome supports it; this path makes no Firebase request.
  3. Choose cloud explicitly. If cloud quality is needed, Clariway previews the exact crop and bounded context before any Firebase AI Logic request.

Built for control

  • Reversible alt-text previews and page reading settings
  • Caption and transcript audits for audio and video
  • Local-first text-to-speech with network voices labelled
  • No analytics, no blanket host permissions, no silent cloud fallback

Clariway is an unpacked Chrome extension for the hackathon build. Follow the installation instructions to build it and load dist from chrome://extensions.
