Clariway

Help screen-reader users understand images that have no alt text.

Clariway checks the active page, asks Gemini Nano for image descriptions on-device, and lets the user review every change. Cloud inference is available only after an explicit review of the image crop and page context.

Install the Chrome build View source Tagged releases

From missing alt text to a reviewed fix

  1. Find. Scan the first 50 images in the active tab; page content stays in the browser.
  2. Describe. Generate an English alt-text candidate with Gemini Nano through Firebase AI Logic.
  3. Review. See the result and apply or undo it as a tab-only preview.
  4. Choose cloud. If local AI is unavailable or a second opinion is useful, inspect the exact payload before approving Gemini cloud inference.

Privacy and accessibility by design

  • Cloud calls use Firebase AI Logic and App Check.
  • No automatic cloud fallback and no page content sent before consent.
  • No analytics or blanket host permissions.
  • Caption audits, transcript reading, speech, and page reading controls are included.

Clariway is a free, open-source Chrome extension for this hackathon build. Gemini Nano requires a compatible Chrome 139+ environment. Follow the installation instructions or check GitHub Releases for a versioned package when one is published.
